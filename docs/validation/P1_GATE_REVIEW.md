# P1 阶段门槛核对

更新于 2026 年 10 月 20 日。本表汇总目前证据，不替代开发方案的退出标准。结论：用户已确认 D05，Codex 0.162.0 + DeepSeek 在该首个可用版本范围内通过 P1，进入 P2；验证脚本仍不是桌面产品，不能推导所有项目均兼容。

## 当前路线判断

直接配置尚不足：需要显式角色适配、输出/费用边界、工具响应检查和 Windows 权限配置。现有证据支持继续评估“固定 Codex 引擎 + 有边界的适配层”，没有证据要求立即更换主引擎，也没有修改上游引擎源码。

当前探针的精确单文件/单命令限制用于验证控制点，不能原样当作面向任意项目的产品。继续工作应收敛到剩余门槛与支持范围，不不断添加展示功能或无关测试平台。完整矩阵后仍有结构性问题，按方案形成路线选择，不无限重试。

- D04：累计 10 元、单次 1 元已确定，账本已实现；当前占用 0.616514 元，含 0.25 元未知用量，未核对账单。
