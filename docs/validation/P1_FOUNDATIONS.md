## 清理记录

已先核对绝对路径、链接情况和前次进程退出，再用 PowerShell 删除本任务生成的旧 p1-discovery、前次中文路径运行副本及项目 npm-cache。精简环境/schema 哈希已在 Git 中保存。共清理 604 个文件，逻辑字节 39,431,316（约 37.6 MiB）；活跃 node_modules、Git 历史、测试源码及报告保留。未清理 C 盘、系统临时目录或其他项目。

新测试运行目录执行后自行清理；此机制不对正在运行的进程或未解决问题目录进行定时清扫。磁盘阈值是开发过程检查要求，不是已实现的应用配额。

实际收尾检查发现 Node 24.8 在本机对中文目录调用递归 rmSync 后目录仍存在，最初英文目录测试未覆盖该问题。已增加中文/空格路径删除后的存在性断言，改为逐文件 unlink 与逐目录 rmdir，并在结束时核对目标消失；Git 生成的只读文件仅在自有运行目录内处理。修复后完整回归及真实握手清理通过，.local/runs 实际为空。此前残留的 6 个已结束合成目录另按绝对路径核对后清理，共 4,589,307 逻辑字节；保留本条失败记录。

## 真实 API 的下一步

2026 年 10 月 19 日读取 [DeepSeek 官方人民币定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 与[英文定价](https://api-docs.deepseek.com/quick_start/pricing/)。中文规范地址直读超时后，通过该官方页面的搜索结果地址读取正文。当前候选 `deepseek-flash`，页面标注模型版本 DeepSeek-V4.1-Flash-1017；请求与返回模型名仍待真实调用确认。

首轮文本协议探针计划使用高峰、未命中缓存的保守费率计算预留：输入 2 元/百万 token、输出 8 元/百万 token；按实际返回 usage 单独记录估算，不假设缓存或低谷折扣。不开启服务端搜索/抓取。实际发请求前必须限制输入体积、输出上限和时间，将每次发送（包括重试）接到账本；无法确定用量则保留预留并停止继续。

直接 API 探针只验证 Responses 协议，不能替代 Codex app-server 实际任务或 Windows 沙箱验收。P2 门槛仍未满足。
