# P3 持续使用与恢复证据

日期：2026 年 10 月 20 日。P3 开发中，尚未完成整个阶段或独立安装验收。

## 已结束聊天继续

每个聊天独立保存引擎历史，每轮明确发送才启动新 turn，重新捕获原项目并配置当前 cwd、任务方式与限额。恢复阶段拒绝模型请求与工具启动；先核对 thread/read 的最后轮次和状态。待审阅或未知状态不能直接继续。

模拟模型与真实 Electron / Codex 0.162.0 / MXC 联测：修复应用后关闭应用，在原项目新增备注，重启并切换只读继续；引擎回传旧工具结果，新工具读到最新备注，只读写入拒绝，原文件不变，新旧副本不同。首次测试因重启后停在“文件”页而未找到应用按钮，显式切换“改动”页后通过；不是引擎或模型恢复失败。

## 正常关闭后的待应用审阅

只在引擎已结束、无未决应用时保存交接记录并释放本应用的项目锁。重开时验证基线、冻结内容、提案与应用日志的哈希，重新计算提案身份，检查实际引擎历史，重新获取项目锁。核对过程没有模型凭据、不发送模型请求，也不调用 turn/start；界面核对按钮不会自动应用文件。

共享的应用逻辑仍使用 Windows 文件与祖先目录句柄检查。逐文件已应用、冲突和拒绝结果保留，不能重复选择已经尝试过的文件；原项目后来变化继续拒绝覆盖。异常退出留下的活动锁、未完成写入意图、变化的证据不视为正常交接，不自动删除锁或重放命令。

13 项原生文件保护测试通过，含新加的部分应用后交接、冻结副本被改变后仍应用审阅字节、用户并发编辑冲突、证据被改拒绝、写入中断后不能交接。桌面工作流、停止三级进程、导航与重启三项测试通过。正常关闭重开审阅的预算账本逐字不变，证明该路径没有计费调用。应用同一数据目录使用单实例锁；状态文件与最新轮次指针改为先持久写临时文件、再原子替换。

共享应用逻辑重构后的完整原生回归为 85/85，无失败或跳过，耗时约 73 秒；首次失败记录保持在原文档中。

- 修复：5 次真实请求、4 个工具；独立基线 1/8，候选 8/8。此次模型先读取再运行配置命令，界面不把非首个工具的退出码冒充任务前基线；独立验收器的初始结果单独保留。
- 关闭后重开待应用审阅：引擎历史和冻结版本一致，原项目未提前改变；仅 src/catalog.mjs 进入提案。点击应用后独立验收 8/8，用户备注不变。
- 再次关闭重启，明确请求只依据历史回顾：1 次真实请求、0 个新工具，引用 catalog.mjs / total，实际正常结束；没有自动重复命令，原项目不变。
- 无人工补丁和人工接管；新增保守估算 0.075476 元。累计 58 次请求，总占用 0.751968 元，其中估算 0.501968 元、历史未知 0.25 元，pending=0，无预算超额；实际账单未核对。

## 聊天存储与明确删除

- 发现并修正容量不一致：原来的单个 workspace.json 上限 8 MiB，小于范围内的有效差异。现在版本 2 索引只保存摘要，各聊天单独持久化，完整内容只加载到选中的聊天或正在操作的任务。旧格式先保存完整独立记录，再原子替换索引，不清空历史。
- 9 个 1 MiB 文件的前后内容形成超过 18 MiB 的记录，保存、重启和读取通过；索引小于 8 KiB，未选中聊天不经 IPC 重复传输正文。单条记录读取上限 224 MiB，覆盖文本 JSON 转义开销；聊天数上限 1000，超限提示先清理。
- 删除入口明确列出聊天、工具记录和已结束副本，确认后清理本应用私有数据。先核对任务归属、完成记录、关闭的应用日志和无链接目录，持久保存删除清单，再将目标移动到独立私有隔离目录删除；原项目、密钥和预算不在清单中。
- 删除中断保留清单，显示未完成；再次明确操作才继续。确认框绑定初始聊天 ID，导航不能改变删除目标。待审阅、未知写入、链接或不匹配记录拒绝清理，不能用删除替代核对。
- `npm run check`、构建通过；存储/迁移/删除边界四项检查加实际 Electron 导航、停止、完整任务与删除三项检查，合计 7/7，无跳过。原生工作流实际删除了两轮的已结束副本，原项目、密钥、预算逐项保持；合成删除中断后继续及 junction 拒绝通过。
- 此包没有新增真实 API 调用，仍占用 0.751968 元。所有成功合成运行结束后清理，.local/runs 为空。

## 停止后的隔离尝试处置

- 新入口仅用于明确放弃从未向原项目应用的隔离尝试。核对持久任务身份、引擎正常退出和实际终态；当前进程持有的锁由原句柄释放，重启后的锁必须匹配原任务且原持有进程已退出。仅 PID 不存在不能自动解锁。
- 放弃后标记已停止、尚未验证，保留副本和工具记录；再单独确认删除才清理。已有原项目应用意图、身份不匹配或引擎历史不可读均保留保护，不自动重放。
- 启动前项目范围拒绝记录零调用与未启动结果，可以明确删除其私有记录，原项目不变。
- `npm test` 86/86；实际 Electron 停止三级进程、无延迟写入、同窗口核对及重启核对两种情况 2/2（约 20.5 / 22.4 秒）。核对过程预算逐字不变；单独删除后原项目仍在。没有新增真实模型调用。
- 首次失败：测试器在写入任务清单后只等 8 秒就寻找子进程标记，启动较慢时提前失败；退出又触发保护提示，掩盖首个失败。改为等待实际进程标记并读取任务终态，清理先等停止完成；产品的命令时限不变。
- 保留的早期中断样本只有聊天 ID、无轮次 ID、零模型请求。实际重开后引擎历史不可读，核对仍拒绝；新增明确错误提示，未声称这个样本恢复成功。该小样本暂保留供后续生命周期改善。
