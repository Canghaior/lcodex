# P1 长命令、停止与重连

2026 年 10 月 20 日。对应 A1/A2/A3、C3/C6；固定 Codex 0.162.0、PowerShell 7.6.5、Node 24.8.0、原生 MXC，沿用环境清单中的二进制哈希。以下故障是模拟响应/传输故障，命令、文件、进程和引擎均实际执行；不算模型任务成功。

## 实际检查

| 场景 / workflow-probe 参数 | 观察结果 | 边界 |
| --- | --- | --- |
| `--long-command` | 12 秒命令超过初次 10 秒等待，仍等待实际完成事件；随后补丁与测试成功，外部验收 1/8→8/8 | 未将返回会话或未知退出码当成完成；不是任意时长、交互式命令的承诺 |
| `--stop-tree` | 已启动父、子、孙三个 Node 进程后停止；终端列表为空，三个 PID 均结束，超过其延迟写入时间后无标记；同批第二调用从未开始 | 执行状态 interrupted，任务未成功，不提供应用按钮；不能推导任意外部服务可撤销 |
| `--deadline-tree` | 实际达到 45 秒命令限制后阻止新释放，interrupt+clean；三级进程均结束，无延迟标记、无第二调用 | 配置中的时间上限确实进入停止流程；不是仅测定时器模拟 |
| `--disconnect-after-write` | 工具完成一次追加后断开响应；引擎历史 failed，文件仅为 ONCE；重启同线程、同 turn，无重放和文件变化 | 已发生的写入保留在隔离副本；失败不代表没有副作用 |
| `--resume-continue`（模拟模型） | 完成任务后退出引擎、重启并读回历史；显式开始新一轮纯文本追问，出站包含此前工具结果；没有新增工具操作或文件变化 | 重启本身不启动任务；主动追问单独计请求，与自动重放不同 |

停止两例均通过独立进程重新打开持久限额记录，确认未完成调用/队列进入 TASK_TOOL_RESULT_UNKNOWN，不能继续调度。验证器可在确认进程全部结束、历史与副作用核对后清理其已保存结论的合成样本；真实产品任务必须保留待核对记录和候选内容。测试成功只表示停止/核对行为符合要求。

上述运行正常退出，无强制结束引擎，原项目不变、成功运行副本已清理。最初构建缺少 existsSync 导入，修正后构建通过，未使用失败构建的旧产物作为证据。

## 接口与保留风险

再次从所选二进制生成实验接口 TypeScript 定义，核对 commandExecution 的 processId/exitCode 以及 backgroundTerminals 列表的 itemId、processId、osPid 和 nextCursor；生成文件读取后清理。

停止次序为先禁止新请求/批次释放，再请求 turn/interrupt，清理线程终端，等待列表为空且没有分页，再读回匹配 turnId 的终态。停止样本另用真实 PID 与延迟写入检查进行独立核对。单个 interrupt 回应不构成“已停止”。[官方 app-server 文档](https://learn.chatgpt.com/docs/app-server)

没有使用 thread/shellCommand 或 process/spawn 绕过线程沙箱。普通工具继续由原引擎在 MXC 内执行。

此前间歇性退出超时的根因仍未确定；新样本正常退出不算根因修复。现有有界退出流程遇到强制结束或未知退出仍报告失败并保留待核对状态，不进入成功或自动重放路径。完整桌面重连交互和更大项目仍待后续阶段验收。
