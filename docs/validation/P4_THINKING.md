# P4 DeepSeek Pro 思考模式适配

2026-10-20；对应 F02/F03/F04/F06/F09 和 P4。用户在暂停后明确要求开启 DeepSeek 思考模式、使用更复杂的模型，本轮按该范围恢复工作；干净 Windows、虚拟机准备和其他发布事项不因此恢复或视为通过。

## 固定配置与费用

- 桌面候选改为 `deepseek-v4-pro`，官方当前对应 `DeepSeek-V4-Pro-0813`；`reasoning.effort=high`。这是用户要求的型号/模式变更，不据型号名称承诺任意任务都优于 Flash。
- [官方型号与人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)核对日期为 2026-10-20。按高峰、缓存未命中保守估算：每百万输入 9 元、输出 27 元；思考 tokens 包含在输出用量中，不重复收费。
- 每次输出上限从 1024 调整为 8192 tokens，覆盖思考与最终答复。保留 96 KiB 请求、最多 8 请求、180 秒任务及 45 秒命令边界；不截掉历史、不在失败后退回 Flash 或关闭思考。
- Pro 请求按实际序列化 UTF-8 字节数加 1024 的输入估算界限，乘输入单价，再加完整输出上限费用，先持久预留再发送。这个保守估算不是官方 tokenizer 或真实账单；返回用量仍需核对，超界如实记录并停止后续请求。费用不足时拒绝调用，不自动减小思考空间或增加用户限额。
- 开发账本继续原累计 10 元、单试验 1 元；重试复用原试验 ID。旧 Flash 测试账本及结论保持，历史记录不改价。个人使用的旧价格确认因型号/价格参考变化失效，需要在设置中核对新的 Pro 价格。
- `validation/deepseek-model.ts` 集中保存当前桌面配置与旧探针配置；Flash 仅用于可复现的历史 P1 探针，不构成桌面自动回退。

## 协议与本地执行

[DeepSeek Responses 接口](https://api-docs.deepseek.com/guides/responses_api/)与[思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)要求保留后续调用所需的思考内容。本轮实际观察到 reasoning 内容使用 `response.content_part` 和 `response.reasoning_text` 事件，而原适配器只处理摘要事件。

现在逐项核对思考内容的 item ID、content index、增量文本、完成文本和最终内容一致性后，才将整组已校验响应交给引擎。工具调用仍需原有参数、权限、整个响应与串行调度检查。思考内容不授予任何权限；第八次只总结、截断/失败不释放工具的条件保持。

思考与工具历史由引擎在应用的私有任务目录保留以供续聊，沿用聊天与任务的删除规则；不另存原始思考正文到诊断报告或 Git。诊断仅记录事件类型/字段名、用量和结果。界面标明 Pro 思考模式及对应价格，不把内部思考内容当成已验证的结论。

2. 首次 Pro/high 合成探针使用强制工具选择，真实 API 返回 HTTP 400，没有用量。没有保存上游错误正文，不能断言具体拒绝原因；预留 0.235485 元全额记入未知消耗。
3. 工具选择改为与桌面一致的 `auto`，同一试验 ID 下两轮成功，模型实际返回思考用量并正确使用合成工具结果；现有适配器因未接受思考正文事件拒绝，整项仍失败。已知用量估算 0.010584 元。
4. 完成思考事件校验后，同一试验 ID 再跑两轮，接口、工具结果关联、最终答案及适配器均通过，耗时 4.733 秒、估算 0.010161 元。工具结果为合成数据，没有文件操作，不能代替桌面任务验收。
5. 最初新增测试的类型检查因异构事件数组推断失败；明确测试数据类型后通过。适配、预算、保留历史专项 20/20；实际 app-server/MXC 配合模拟模型的四场景 4/4，确认七轮实际读取后的思考与工具历史都回传，最后一次拒绝命令/补丁及截断不执行。
