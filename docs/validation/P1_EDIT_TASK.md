## 验收保护与适用范围

入口只新增允许名称为 apply_patch 的 custom 工具与配对历史；其他 custom 和服务端工具仍拒绝。所有 SSE 工具 item、输入增量和结束内容必须一致，一个响应最多一个工具调用；没有把未检查的流先交给引擎执行。

补丁先在内存预览，拒绝其他路径、多 hunk、创建/删除/移动，以及与基线不匹配的修改。本次候选源码被限制为两个固定签名的算术函数：仅允许指定变量、数值和算术符号，不允许 imports、process、动态代码或任意函数调用。通过这个限制后，独立协调程序在未注入文件/进程 API 的计算上下文中检查六组结果，超时 100 毫秒；验收代码不在 Agent 可写目录。

这里的语法限制是合成样本的验证控制，不是产品支持所有 JavaScript 的方案；Node vm 也不被视为安全沙箱。真实项目运行仍需 OS 沙箱与独立验收保护，不能直接导入任意模型生成模块。此次是在一个受限任务中同时修 bug 和加小功能，不等于两类任务分别完成三次独立验收，也不证明通用项目成功率。人工介入是预先设计任务、语法和工具边界，没有手改本次模型补丁或答案。
