# P1：DeepSeek 直接 Responses 探针

日期：2026 年 10 月 19 日。范围：P1 A1/A2 的最小直接协议样本，以及请求入口预算控制；尚未通过 Codex 引擎、项目任务或 Windows 执行验收。

## 配置与证据

- 官方地址 `https://api.deepseek.com/responses`；模型请求和返回名均为 `deepseek-flash`。经过认证的模型列表返回 `deepseek-flash`、`deepseek-v4-pro`，不是根据旧型号名称猜测。
- `stream=true`、`store=false`、`max_output_tokens=1024`；复测显式设 `reasoning.effort=none`。输入请求体限制 16 KiB，只允许合成文本与函数工具，超时 60 秒，不自动重试，不启用搜索或文件上传。
- 试验 `responses-add-v1`：首轮要求调用 add(19,23)，本机核对工具名、参数和 call_id，回传结果 42；第二轮携带完整历史和关联工具结果，最终文本必须恰为 42。不执行 shell、不发送项目文件。

| 执行 | 实际结果 | 用量与预算处理 |
| --- | --- | --- |
| 首次请求，未指定思考模式 | HTTP 400，停止后续请求；未保留原始错误正文，因此不能确认服务端具体拒绝原因 | 未收到 usage；0.25 元完整预留，禁止自动重试 |
| 关闭思考后的第一轮 | response.completed，19 个事件；返回唯一符合预期的函数调用 | 输入 310、输出 47 token；保守估算 0.000996 元 |
| 同次复测第二轮 | response.completed，9 个事件；历史和工具关联完成，回答 42 | 输入 92、输出 1 token；保守估算 0.000192 元 |

首次 400 与默认思考模式下强制工具调用的限制相符，关闭思考后的复测成功；这支持配置调整，但没有原始错误证据，不把原因写成已证实。首次失败记录和复测记录分别保留于被忽略的 .local/reports，不覆盖。

## 费用规则

价格核对使用官方人民币高峰、未命中缓存的输入 2 元/百万 token、输出 8 元/百万 token。已收到 usage 的两次合计估算 0.001188 元；未核对真实账单。首次未知请求经检查属于受限文本请求，显式按完整 0.25 元永久占用本次试验和累计预算，仍标识未知用量，不记零、不退还额度。

当前累计保守占用 **0.251188 元 / 10 元**，同一试验也占用 0.251188 元 / 1 元；共 3 次推理 HTTP 发送，另有 1 次模型元数据 GET。没有 pending 或估算超额。请求上限仍为每试验 8 次，重启或复测不清零。

新增显式未知费用归档操作仅供验证监督使用：核对请求受已验证上限约束后，按完整预留占用预算，再人工决定是否复测；默认遇到未知费用仍阻止新请求。这不是自动恢复、账单核对或应用界面功能。账本不属于缓存，清理时必须保留。
